Internal Technician Verification

This section is for internal users only.

Technician Verification Checklist (Internal)

A. Lead Qualification

  • Replacement-only request confirmed (not repair)
  • Customer within service area
  • Category and photos sufficient
  • Model/serial readable
  • Follow-up needed before quote? (Yes / No)

B. Existing Asset Verification

  • Manufacturer, model, serial validated
  • Unit type and capacity verified from tag/manual
  • Dimensions and electrical requirements confirmed
  • Refrigerant/system type verified
  • Installation environment confirmed

C. Replacement Logic

  • Direct replacement available?
  • Footprint / clearance / door-swing constraints
  • Utility compatibility and code considerations
  • Performance needs and upsizing review

D. Quoting Path

  • Like-for-like replacement
  • Equivalent alternate
  • Upgrade replacement
  • Discontinued model replacement
  • Custom review required

E. Internal Quote Notes

  • Recommended + alternate models
  • Warranty and lead-time notes
  • Accessories and install considerations
  • Removal/disposal and exclusions
  • Additional field visit required?

F. Pricing / Sales Readiness

  • Equipment cost available
  • Freight/delivery included
  • Labor/startup scope confirmed
  • Tax status known
  • Ready for sales release
