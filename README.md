# bmsquote

Benfield Mechanical Services replacement quote intake website prototype.

## What this includes

- Customer-facing 7-step guided intake focused on **replacement quote requests only**.
- Required-field gating so users complete essential information before moving forward.
- Smart equipment-specific follow-up prompts that update dynamically.
- Internal technician verification checklist in a separate collapsible internal section.

## Run locally

Open `index.html` in a browser.

## Scope notes

Phase 1 intentionally focuses on replacement quoting (not repair diagnostics).
